# 💻 IT Support & Troubleshooting

## About This Project
This project documents basic IT support knowledge, Windows troubleshooting techniques, and common technical solutions.

## 1. Windows Troubleshooting
- Restarting Windows services
- Checking Windows updates
- Running System File Checker (SFC)
- Troubleshooting startup issues

## 2. Hardware Troubleshooting
- Keyboard and mouse issues
- Monitor display problems
- RAM and storage checks
- Power and connectivity issues

## 3. Software Troubleshooting
- Application installation errors
- Software crashes
- Driver issues
- Operating system errors

## 4. Useful Windows Commands

| Command | Purpose |
|---|---|
| `sfc /scannow` | Scans and repairs system files |
| `ipconfig` | Displays network configuration |
| `ping` | Tests network connectivity |
| `tasklist` | Displays running processes |
| `systeminfo` | Displays system information |

## 5. Basic IT Support Process
1. Identify the problem.
2. Understand the user's issue.
3. Diagnose the root cause.
4. Apply an appropriate solution.
5. Test the result.
6. Document the resolution.

To develop practical IT Support and technical troubleshooting skills.
